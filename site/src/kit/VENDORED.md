# Vendored: the Stageshow kit

This folder is `stageshow/kit/` from [benjitaylor/skills](https://github.com/benjitaylor/skills)
at commit `8020574`, copied unchanged. It is MIT licensed (`LICENSE`); the
notices for the brand artwork it carries are in `NOTICE.md` and
`brands/SOURCES.md`.

The website's illustrations (`site/src/demos/`) are built on it. Change it by
copying a newer `kit/` over this one, not by editing it here, so it stays one
copy of upstream. `pnpm lint` doesn't lint it, as it doesn't lint other
generated or vendored code.
