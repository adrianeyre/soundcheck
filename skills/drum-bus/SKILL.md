name: drum-bus
title: Drum bus
category: Mixing
description: Put the drums on one Bus with gentle compression, so they hit together and sit in the mix as one kit.
argument-hint: "[punchy or smooth]"
---

Glue the drums together on one Bus.

1. Find the drum Tracks: the Drum Track and any Track named as a drum or percussion. If the Project already has a Drum Bus, use it.
2. Load the routing and sounds tools, add a Bus called Drums, and set each drum Track's output to it.
3. Add a Compressor to the Bus: ratio about 4:1, attack about 30 ms so the hits come through, release about 100 ms, and the threshold so the loudest hits come down about 3 dB (5 dB for punchy). Set the makeup gain to match.
4. Add an EQ after it with a gentle lift: low shelf about +2 dB at about 60 Hz for weight, high shelf about +1.5 dB at about 8 kHz for snap. Skip it if the musician asks for smooth.
5. Analyse the Bus's Tracks together in the mix before and after, and check the true peak is still under the ceiling.

Say which Tracks now feed the Drum Bus, and its settings.
