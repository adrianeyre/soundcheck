---
name: bassline
title: Bassline
category: Songwriting
description: Write a bassline that follows the song's key and locks to the kick drum.
argument-hint: "[key or style]"
---

Write a bassline for the song.

1. Read the notes of the Pattern Clips that are already there, and find the song's key and chords from them. If the musician names a key, use it; if there are no notes to go on, use A minor.
2. Read the kick drum's notes, if there is a Drum Track, so the bass can land with the kick.
3. Add an Instrument Track called Bass with the Synth on a bass preset, or use the Bass Track the Project already has.
4. Write Pattern Clips that play the root of each chord, mostly on the kick's beats, in the octave below middle C, with a passing note into each change of chord. Match the length of the Clips around it.
5. Set the Bass Track's volume so it sits under the drums rather than over them.

Say the key you used and how many bars you wrote.
