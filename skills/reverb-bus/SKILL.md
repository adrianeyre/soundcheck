---
name: reverb-bus
title: Shared reverb
category: Mixing
description: Add one Reverb Bus and send the Tracks you name to it, so they sit in the same space.
argument-hint: "[Tracks to send, or all]"
---

Give Tracks a shared space with one reverb, rather than a Reverb on each.

1. If the Project already has a Bus with a Reverb on it, use that one. Otherwise load the routing tools, add a Bus called Reverb, and add a Reverb Effect to it with its mix fully wet.
2. Add a Send to that Bus from each Track the musician names; without names, from every Track except drums and bass. Start each Send at about 0.25, a little more for pads and vocals, less for anything percussive.
3. If a Track already has its own Reverb, leave it, and say so.

Say which Tracks now send to the Reverb Bus, and at what level.
